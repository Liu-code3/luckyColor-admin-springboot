# LuckyColor Admin Spring Boot v1.0.0-alpha.1

## 发布说明

- 版本：`1.0.0-alpha.1`
- 交付形态：Spring Boot 单体服务
- 运行基线：`JDK 17`、`Spring Boot 3.5.13`、`MySQL 8`、`Redis 7`
- 持久层：`MyBatis-Plus 3.5.12`
- 认证方式：`JWT + 本地账号配置`
- 多租户模式：共享库共享表，按 `tenant_id` 隔离

## 已覆盖能力

- 租户中心：租户、租户套餐、租户初始化、租户审计
- 认证授权：登录验证码、登录登出、用户资料、动态路由、权限守卫、数据权限、安全审计
- 系统管理：用户、角色、菜单、部门、字典、系统配置、公告、操作日志
- 平台能力：工作台、文件上传下载、国际化、用户偏好、水印配置、代码生成元数据
- 基础设施：统一响应、统一异常、Redis 缓存、健康检查、OpenAPI 文档

## 版本信息

- OpenAPI 版本与 Maven 版本保持一致
- `GET /api/version` 可查看构建版本和发布阶段
- 当前发布阶段：`alpha`

## 启动建议

```powershell
$env:SPRING_PROFILES_ACTIVE="prod"
$env:DB_HOST="127.0.0.1"
$env:DB_PORT="3306"
$env:DB_NAME="luckycolor_admin"
$env:DB_USERNAME="root"
$env:DB_PASSWORD="replace-me"
$env:REDIS_HOST="127.0.0.1"
$env:REDIS_PORT="6379"
$env:JWT_SECRET="replace-with-a-strong-secret"
$env:STORAGE_ROOT_PATH="D:/zl/storage"
./mvnw spring-boot:run
```

## 首版限制

- 当前登录用户仍以 `application.yml` 本地账号配置为准，尚未切换为数据库账号源
- 文件服务当前提供本地磁盘存储，尚未接入对象存储
- 代码生成模块当前提供元数据维护，不包含模板生成与下载
